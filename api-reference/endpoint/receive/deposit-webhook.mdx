### 接口地址
**POST** `商户配置的回调地址`

<Tip>
    每笔收款订单，会回调两次，点击 [这里](/user-guide/useful-docs/webhook) 了解详细的回调规则。
</Tip>

### 请求参数

| 参数                  | 数据类型      | 必填 | 描述                    |
|---------------------|-----------|------|-----------------------|
| **webhookType**     | `String`  | 是    | 回调类型，这里为 `Deposit`。   |
| **id**              | `String`  | 是    | 订单ID                  |
| **status**          | `String`  | 是    | 订单状态，见订单枚举            |
| **chainName**       | `String`  | 是    | 区块链名                  |
| **tokenName**       | `String`  | 是    | 币种名                   |
| **fromAddress**     | `String`  | 是    | 发送方地址                 |
| **toAddress**       | `String`  | 是    | 接收方地址，即您的充值地址。        |
| **txHash**            | `String`  | 是    | 链上交易哈希                |
| **amount**          | `String`  | 是    | 充值的数量                 |
| **blockHigh**       | `Integer` | 是    | 交易所在的区块高度。            |
| **blockConfirmNum** | `Integer` | 是    | 回调时的区块确认数，表示交易被确认的次数。 |
| **createdTime**     | `Long`  | 是    | 创建时间（UTC 时间）         |
| **timestamp**     | `Long`  | 是    | UNIX 时间戳（毫秒）         |
