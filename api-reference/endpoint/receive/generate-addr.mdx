---
title: '创建地址'
description: '生产某条链上的区块链地址，用于充值收款。'
openapi: 'POST /'
---

### 接口地址
**POST** `/v1/account/address/create`



### 请求参数
| 参数         | 类型       | 是否必填 | 描述                                                   |
|--------------|------------|----------|--------------------------------------------------------|
| **chainName** | `Integer`   | 是       | 区块链名称，用于指定目标链。                              |
| **timestamp** | `Long`      | 是       | UNIX 时间戳（毫秒）。                           |
| **addressNum** | `Integer`   | 否       | 要生成的地址数量，最大值为 5，默认为 1。                    |
| **alias**      | `String`    | 否       | 地址的别名，用于标识和更好地辨认地址。                     |
| **callbackUrl** | `String`    | 否       | 回调地址，收款信息将优先通知到该地址。                      |

---

### 响应参数
| 参数       | 类型       | 是否必填 | 描述       |
|------------|------------|----------|------------|
| **address** | `String`    | 是       | 生成的区块链地址。 |


### 响应示例

```json
{
    "code": 200,
    "msg": "success",
    "timestamp": "1725620148293",
    "data": {
        "address": [
            "TTxcUtirXHxAhUqxnZxTNy3qKonq7E5HAH"
        ]
    }
}
```
