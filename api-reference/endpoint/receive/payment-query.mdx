### 接口地址
**GET** `/v1/account/order/query`

### 请求参数

| 参数             | 类型       | 必填 | 描述                                       |
|----------------|----------|----|------------------------------------------|
| **id**         | `String` | 否  | 平台返回的订单 ID。                              |
| **businessId** | `String` | 否  | 商户自定义的业务 ID。`id` 或 `businessId` 必须传其一。 |
| **timestamp**  | `Long`   | 是  | UNIX 时间戳（毫秒）。                            |


### 响应参数

| 参数               | 类型       | 必须 | 描述                             |
|------------------|----------|----|--------------------------------|
| **id**           | `String` | 是  | 平台定义的订单唯一标识。                   |
| **businessId**   | `String` | 是  | 商户自定义的业务 ID。                   |
| **redirectUrl**  | `String` | 是  | 支付完成后重定向的页面URL。                |
| **amount**       | `Double` | 否  | 商户定义的收款金额(如果是不固定金额，此值为空)。      |
| **tokenName**    | `String` | 是  | 商户定义的收款货币名称，例如 `USDT`、`BTC` 等。 |
| **chainName**    | `String` | 是  | 区块链网络名称，例如 `Ethereum`、`Bsc` 等。 |
| **address**      | `String` | 是  | 收款地址，用于接收支付的区块链地址。             |
| **status**       | `String` | 是  | 订单状态，表示订单当前的处理状态。              |
| **txHash**       | `String` | 否  | 区块链交易哈希，当用户支付完成时返回此值。          |
| **amountActual** | `Double` | 否  | 用户实际支付的金额，当用户支付完成时返回此值。        |
| **createdDate**  | `Long`   | 是  | 创建时间（UTC）                 |
| **expiryDate**   | `Long`   | 是  | 过期时间（UTC) |
