### 接口地址  
**POST** `/v1/account/withdraw`

### 请求参数

| 参数           | 类型      | 必填 | 描述                                                                 |
|----------------|-----------|----------|----------------------------------------------------------------------|
| **tokenName**   | `String`  | 是       | 提现的币种。                                                         |
| **chainName**   | `String`  | 是       | 接收方的区块链名称，可通过币种信息接口获取。                             |
| **toAddress**   | `String`  | 是       | 接收方地址。提现前可通过“地址是否合法”接口验证地址的合法性。               |
| **amount**      | `String` | 是       | 转账数量。最小提现数量与小数位需符合要求(可通过币种信息接口获取)        |
| **timestamp**   | `Long`    | 是       | 请求时间的 Unix 时间戳（毫秒）。                                        |
| **businessId**  | `String`  | 否       | 商户自定义的订单 ID，需保证唯一性。如重复，该笔转账将被取消。                 |
| **tag**         | `String`  | 否       | 订单备注信息。                                                        |
| **fee**         | `String`  | 否       | 区块链转账的费用设定（备用字段）。                                         |
| **callbackUrl** | `String`  | 否       | 回调地址，订单的处理信息会优先通知到此地址。                               |
| **confirmFirst**| `Integer` | 否       | 当转账成功打包进区块时，首次回调所需的区块确认数。                         |
| **confirmNeeded**| `Integer`| 否       | 交易所需的总区块确认数，需大于 `confirmFirst` 值。                     |

---

### 响应参数

| 参数         | 类型      | 必须 | 描述                  |
|--------------|-----------|----------|-----------------------|
| **id**       | `String`  | 是       | 订单的唯一 ID，用于标识该笔转账。  |

### 响应示例

```json
{
