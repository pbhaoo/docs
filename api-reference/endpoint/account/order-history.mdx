---
title: '查询账户订单历史'
description: '获取充值或提现的历史订单信息,可用于对账。'
openapi: 'GET /'
---

### 接口地址
**GET** `/v1/account/order/history`

### 请求参数

| 参数         | 类型      | 是否必填 | 描述                                                                 |
|--------------|-----------|----------|----------------------------------------------------------------------|
| **type**      | `String`  | 是       | 操作类型，支持的取值：`deposit`（充值）或 `withdraw`（提现）。           |
| **timestamp** | `Long`    | 是       | 请求时间的 Unix 时间戳（毫秒）。                                        |
| **tokenName** | `String`  | 否       | 币种名称，默认为查询全部币种。                                           |
| **startTime** | `Long`    | 否       | 查询起始时间戳，默认为当前时间 30 天前。                                    |
| **endTime**   | `Long`    | 否       | 查询结束时间戳，默认为当前时间戳。                                        |

**注意**: 查询的最大时间范围为 30 天，即：`endTime - startTime <= 30 Days`。

---

### 响应参数（充值）

| 参数           | 类型      | 是否必填 | 描述                                    |
|----------------|-----------|----------|-----------------------------------------|
| **id**         | `String`  | 是       | 订单 ID              |
| **chainName**  | `String`  | 是       | 区块链名称             |
| **tokenName**  | `String`  | 是       | 币种名称           |
| **amount**     | `String`  | 是       | 充值的数量                              |
| **fromAddress**| `String`  | 是       | 发送方地址             |
| **toAddress**  | `String`  | 是       | 接收方地址              |
| **txId**       | `String`  | 是       | 链上交易哈希     |
| **createdTime**| `String`  | 是       | 创建时间(UTC)                        |
| **completeTime**| `String` | 是       | 完成时间(UTC)                     |
| **status**     | `String`  | 是       | 订单状态，详见“枚举定义”中的状态解释。        |

---

### 响应参数（提现）

| 参数           | 类型      | 是否必填 | 描述                                    |
|----------------|-----------|----------|-----------------------------------------|
| **id**         | `String`  | 是       | 订单 ID             |
| **businessId** | `String`  | 否       | 商户自定义的订单 ID        |
| **chainName**  | `String`  | 是       | 区块链名称            |
| **tokenName**  | `String`  | 是       | 币种名称          |
| **amount**     | `String`  | 是       | 提现的数量                              |
| **toAddress**  | `String`  | 是       | 接收方地址              |
| **txId**       | `String`  | 是       | 链上交易哈希    |
| **networkFee** | `String`  | 是       | 网络手续费    |
| **platformFee**| `String`  | 是       | 平台佣金，表示平台收取的服务费用。            |
| **totalFee**   | `String`  | 是       | 总费用，包括网络手续费与平台佣金之和。          |
| **createdTime**| `String`  | 是       | 创建时间(UTC)                        |
| **completeTime**| `String` | 是       | 完成时间(UTC)                        |
| **status**     | `String`  | 是       | 订单状态，详见“枚举定义”中的状态解释。        |
