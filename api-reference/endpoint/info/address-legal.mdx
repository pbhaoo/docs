openapi: 'POST /'
---


### 接口地址  
**POST** `/v1/common/address/legal`

### 请求参数

| 参数       | 类型 | 必须 | 描述         |
|------------|----------|----------|--------------|
| **chainName**  | `String`   | 是     | 链名           |
| **address**    | `String`   | 是     | 需要判断的区块链地址   |

### 响应参数

| 参数   | 类型 | 必须 | 描述                      |
|--------|----------|----------|---------------------------|
| **result** | `Bool`     | 是     | `False` 为不合法，`True` 为合法 |

### 响应示例

```json
{
    "code": 200,
    "msg": "success",
    "timestamp": "1725619914435",
    "data": {
        "result": true
    }
}
```
