openapi: 'POST /'
---

### 接口地址
**GET** `/v1/common/convert/fiatToCrypto`

### 请求参数

| 参数             | 类型       | 必填 | 描述                                       |
|----------------|----------|-------|------------------------------------------|
| **inCurrency** | `String` | 是     | 原始法定货币的币种代码（如 USD、EUR 等）。         |
| **inAmount**   | `String` | 是     | 需要进行转换的金额。                             |
| **outCurrency**| `String` | 是     | 目标加密货币的币种代码（如 USDT、ETH 等）。         |
| **timestamp**  | `Long`   | 是     | UUNIX 时间戳（毫秒）        |


### 响应参数

| 参数               | 类型       | 必须 | 描述                             |
|------------------|----------|----|--------------------------------|
| **outAmount**           | `string` | 是  | 转换后的金额                   |

---

### 响应示例

```json
{
    "code": 200,
    "msg": "success",
    "timestamp": "1725674596300",
    "data": {
        "outAmount": "588.66",
    }
}
